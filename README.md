# lu-wardrobe

A minimal static page ("Closet de Lu") that lists transparent product photos.
Each item is a hand-drawn frame with the photo (5/9 of the width) followed by
its description, size, price and a "Habla conmigo" link that opens WhatsApp
with a message naming the item (the number is `PHONE` in `main.js`). Phones
show one item per row; screens 900 px and wider show two, and the photos grow
with the screen.

The frames are generated by a small WebAssembly module (`frame.wasm`, about
9 KB, built from `src/frame.c`) in three styles: loops, scallops and dashes.
Style and colour are assigned pseudo-randomly per position, so they stay the
same on every visit; the colour list is `COLORS` in `main.js`. The same module
decodes the blurred placeholders. There are no dependencies and no build step
for the site itself.

## Edit the items

Everything shown comes from `items.json`:

```json
{ "image": "img/blue-roll-neck-sweater.webp", "description": "…", "size": "M", "price": "153", "category": "Sacos", "sold": false }
```

Empty `size`, `price` and `category` fields are simply not shown. An item
with `"sold": true` is greyed out and shows "Vendido" instead of the
WhatsApp link.

To add an item: put a PNG with a transparent background in `img/`, add an
entry pointing at it, then run

```sh
python3 tools/optimize.py
```

That converts the PNG to WebP, points the entry at the new file and writes its
`thumb` (the blurred placeholder shown while the image loads, decoded by
`frame.wasm`). It needs Pillow (`pip install pillow`). The original `.png` can
then be deleted.

## Run locally

WebAssembly and `fetch` need a web server (opening `index.html` directly will
not work):

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish on GitHub Pages

1. Push this repo to GitHub.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.

## Rebuild the WebAssembly

Only needed if you change `src/frame.c`. Requires clang with the wasm32 target
and `wasm-ld` (on macOS: `brew install llvm lld`).

```sh
./build.sh
```
